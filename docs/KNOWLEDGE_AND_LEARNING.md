# Skills and learning

Set `skills.path` explicitly. The bridge reads category Markdown only inside that root,
caps files/context, and retains relative paths, line numbers, hashes and untrusted provenance.
No external helper is executed and no external file is rewritten. Configure the checkout
root rather than flattening its references into one prompt. Missing skills do not prevent
the built-in fixture solver from operating.

Accepted PRESTIGE knowledge is searched first, then relevant skill chunks. The initial
implementation uses lexical matching, not embeddings or semantic novelty guarantees.
Automatic capture handles only reviewed base64/hex/XOR/ZIP derivation chains after trusted
digest verification and replay. Schema validation uses the exact copied upstream schema;
the original MIT notice is preserved. Records include mechanism, preconditions, failure modes,
materiality, reproducibility, provenance and confidence. Values, hosts, keys and flags are omitted.

Exact transform chains deduplicate locally. Related skills route the candidate to an inbox;
inbox records are not fed back as verified retrieval. This deliberately narrow generalizer
does not claim to capture every novel exploit or discover global novelty. No model-authored
record bypasses verification. There is no writable skill-sync or auto Git push path.
